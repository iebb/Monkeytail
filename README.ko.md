Monkeytail은 SwiftUI로 만든 iPhone, iPad, Mac, Apple Vision Pro용 오픈 소스 API 클라이언트입니다. cURL, Postman, Insomnia, OpenAPI를 가져올 수 있으며 스크립트와 테스트를 지원합니다. 계정이 필요 없습니다.

## 빌드

Xcode에서 `Monkeytail.xcodeproj`를 열고 **Monkeytail**, **MonkeytailMac** 또는 **MonkeytailVision** 스킴을 실행합니다. `project.yml`을 수정한 후에는 `xcodegen generate`를 실행하십시오.

## 테스트

```sh
swift test
```

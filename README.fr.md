Monkeytail est un client d’API open source pour iPhone, iPad, Mac et Apple Vision Pro, développé en SwiftUI. Il importe cURL, Postman, Insomnia et OpenAPI, et prend en charge les scripts et les tests. Aucun compte requis.

## Compiler

Ouvrez `Monkeytail.xcodeproj` dans Xcode et lancez le schéma **Monkeytail**, **MonkeytailMac** ou **MonkeytailVision**. Après avoir modifié `project.yml`, exécutez `xcodegen generate`.

## Tests

```sh
swift test
```

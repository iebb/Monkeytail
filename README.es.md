Monkeytail es un cliente de API de código abierto para iPhone, iPad, Mac y Apple Vision Pro, creado con SwiftUI. Importa cURL, Postman, Insomnia y OpenAPI, y admite scripts y pruebas. No necesita cuenta.

## Compilar

Abre `Monkeytail.xcodeproj` en Xcode y ejecuta el esquema **Monkeytail**, **MonkeytailMac** o **MonkeytailVision**. Después de editar `project.yml`, ejecuta `xcodegen generate`.

## Pruebas

```sh
swift test
```

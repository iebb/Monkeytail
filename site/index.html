Your Postman collections. None of the logins.

Monkeytail is a native, open-source API client for iPhone, iPad, Mac and Apple Vision Pro. Bring your Postman and Insomnia collections, keep your scripts, and get straight to sending requests.

Free · No in-app purchases · No account · One download for iPhone, iPad, Mac and Vision Pro

A drop-in replacement for Postman and Insomnia

Open the collections you already have and run them the same way. No Monkeytail account, no login wall, no cloud workspace and no telemetry.

Import everything

Postman collections, environments, globals and data dumps; Insomnia v4 and v5; Bruno, Hoppscotch, Thunder Client, HAR, .http files, OpenAPI and cURL. Pick a whole folder at once.

Or pull from the cloud

Sign in to Postman, Insomnia or Hoppscotch once to pull your synced workspaces, or point at a GitHub repository. The session is used for that import only and never saved.

Your scripts keep working

A Postman-compatible pm API with pm.test, pm.expect, pm.sendRequest, CryptoJS, lodash and moment. Insomnia and Bruno scripts run too.

The same mental model

Workspaces, collections and nested folders that inherit auth, headers, variables and scripts. Environments, globals and {{variables}}, including {{$guid}}.

Export back any time

Postman v2.1, Insomnia v4 or a full-fidelity Monkeytail JSON file. Your data is never locked in.

Native, not a web view

Built in SwiftUI for each Apple platform, with keyboard shortcuts on the Mac and a thumb-friendly editor on iPhone.

A full API client in your pocket

The same workspace on iPhone, iPad and Mac, synced through your own iCloud Drive.

Everything else you'd expect

And a few things you might not.

  • HTTP, GraphQL with introspection, WebSocket and server-sent events
  • OAuth 2.0 with PKCE, OAuth 1.0, JWT, AWS Signature V4, Digest, API keys, Basic and Bearer
  • Collection runner with iterations and CSV/JSON data files, exporting JSON or JUnit reports
  • Visual assertions, saved examples, offline mocks and a local mock server
  • Pretty JSON, a response tree, search, comparison, images, audio, video and hex
  • Code generation in 13 languages, plus cURL import and export
  • Timing breakdowns, TLS details, HTTP/HTTPS/SOCKS5 proxies and client certificates
  • Optional Chrome, Firefox and Safari TLS profiles on iPhone, iPad and Mac
  • Six themes, your own colours and fonts
  • English, Spanish, French, Japanese, Korean and Simplified Chinese
  • An Apple Watch companion for favourite requests
  • Open source under the BSD 3-Clause License

Private by design

Requests go straight from your device to your servers. There is no Monkeytail backend in between.

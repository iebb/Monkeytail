Monkeytail は、SwiftUI で作られた iPhone、iPad、Mac、Apple Vision Pro 向けのオープンソース API クライアントです。cURL、Postman、Insomnia、OpenAPI を読み込め、スクリプトとテストに対応しています。アカウントは不要です。

## ビルド

Xcode で `Monkeytail.xcodeproj` を開き、**Monkeytail**、**MonkeytailMac**、**MonkeytailVision** のいずれかのスキームを実行します。`project.yml` を編集したら `xcodegen generate` を実行してください。

## テスト

```sh
swift test
```

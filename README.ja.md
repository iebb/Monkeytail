# Monkeytail

[English](README.md) · [Español](README.es.md) · [Français](README.fr.md) · **日本語** · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md)

**iPhone、iPad、Mac、visionOS 向けのネイティブなリクエストデバッガです。コンパクトな Apple Watch コンパニオンも備えています。** コマンドを読み込み、リクエストを編集し、レスポンスを確認できます。SwiftUI で構築されており、iPhone ではコンパクトなエディタ、デスクトップでは画面に応じて変化するワークスペースを提供します。

無料です。App 内課金はありません。アカウントは不要です。Kitta Co がデータを収集することはありません。

## 実行

**`Monkeytail.xcodeproj`** を開きます。iPhone/iPad には **Monkeytail**、Mac には **MonkeytailMac**、visionOS には **MonkeytailVision**、Watch コンパニオンには **MonkeytailWatch** を選択します。iOS 17、macOS 14、visionOS 1、または watchOS 10 が必要です。Mac でのクライアント証明書の読み込みには macOS 15 が必要です。ビルドと検証には Xcode 27 を使用しています。実機や iCloud を有効にした Mac ビルドでは、署名チームを選択してください。Mac の Debug ビルドはアドホックなローカルテスト用に別のサンドボックス entitlements を使用し、Release では共有 iCloud コンテナが有効になります。

生成済みの Xcode プロジェクトはリポジトリに含まれています。`project.yml` でターゲットの設定を変更した場合は、[XcodeGen](https://github.com/yonaskolb/XcodeGen) で再生成してください。

```sh
xcodegen generate
```

初期コレクションは httpbin.org を使用します。リクエストは **送信** をタップするか、送信のキーボードショートカットを使ったときにのみ送られます。独自のサーバを使うには、Playground 環境の `base_url` を置き換えてください。

## 主な機能

- ネイティブのリクエストエディタ：メソッド、URL、`:name` パス変数、有効/無効を切り替えられるヘッダとクエリパラメータ（Postman 形式の一括編集に対応）、JSON/テキスト/URL エンコード/マルチパートの本文とバイナリファイルのアップロード、継承される認証、Bearer/Basic/Digest、API キー、OAuth 1.0 署名、JWT Bearer（HS/RS/PS/ES 256–512、送信のたびにローカルで署名し、ヘッダまたはクエリパラメータに付与）、PKCE とリフレッシュに対応した OAuth 2.0、AWS SigV4、タイムアウト、リダイレクト。
- cURL の読み込みと書き出し。シェルのクォート、複数行のコマンド、データ、JSON、Cookie、Basic 認証と `--digest` 認証、プロキシの選択に対応しています。インポータはテキストを解析するだけで、シェルを起動することはありません。
- ヘッダ、認証、変数、スクリプトを継承するコレクションと入れ子のフォルダ。追加、名前変更、複製、削除、検索、ローカルへの自動保存に対応しています。iCloud Drive 同期はデフォルトでオンになっており、デバイスの既存のセッションを使用します。Monkeytail のアカウントは不要です。
- 名前付きの環境、ワークスペースのグローバル変数、リクエスト全体での `{{variable}}` の置換。入れ子の変数に対応し、未定義の変数や循環参照を検出します。`{{$guid}}`、`{{$timestamp}}`、`{{$randomEmail}}` などの Postman の動的変数も使用できます。解決後の値は URL の下に表示され、`{{` と入力すると変数の候補が表示されます。
- コレクションとフォルダのランナー：反復回数、待機時間、CSV/JSON データファイル、`pm.execution.setNextRequest`/`skipRequest`、成功/失敗のリアルタイム表示、JSON または JUnit 形式のレポート書き出し。実行はローカルで行われ、アカウントやクラウドのランナーは不要です。
- 実際の HTTP 通信、キャンセル、レスポンスの共有、ホップごとの DNS/接続/TLS/アップロード/サーバ/ダウンロードの診断。通信層が報告したヘッダと、上限付きで送信した本文を表示します。
- Chrome、Firefox、Safari 向けのオプションの[ブラウザ TLS と HTTP/2 のプロファイル](docs/BrowserProfiles.md)。iOS と Mac では iOS と Android のプリセットも含まれます。visionOS では System TLS を使用します。固定バージョンのブラウザライブラリには visionOS 向けのスライスがないためです。固定バージョンの curl-impersonate を使ってローカルで動作し、証明書の検証は有効なままです。
- JSON の整形表示、コアライブラリでのミニファイ、シンタックスカラー、展開可能なツリー、行検索、コピー、リクエスト本文の整形。
- MIME タイプに応じた画像プレビュー（ピンチでズーム）、ネイティブのオーディオ/ビデオ再生、オフセット/ASCII 付きの Hex ビューアとバイナリビューア。対応していないメディアはバイト列として確認するか、保存できます。
- ローカルで実行される JavaScript のリクエスト前フックとレスポンス後フック。Postman 互換の `pm` のサブセットを備えています：Chai 形式の `pm.expect`、`pm.response.to.*`、`pm.sendRequest`、環境/コレクション/グローバル変数、Cookie、組み込みの CryptoJS、lodash と moment のサブセット、コンソールログ。スクリプトは読み込んだものも含め、送信のたびに実行されます。
- システムのネットワーク設定、またはカスタムの HTTP CONNECT、TLS でラップした HTTPS CONNECT、SOCKS5 プロキシ。資格情報は任意で設定でき、カスタムプロキシが失敗しても直接接続にフォールバックすることはありません。
- OpenAPI/Swagger の JSON と YAML の読み込み。パラメータのヒント、例、移植性のある JSON Schema 検証に対応しています。
- GraphQL のクエリ/変数/オペレーションの編集、イントロスペクション、検索可能なスキーマフィールドの候補表示。
- WebSocket と SSE のタイムライン。テキスト/JSON/バイナリの確認、フィルタ、ping、キャンセル、再接続に対応しています。
- 環境ごとのデバイスローカルな Cookie jar、ホスト完全一致の PKCS#12 クライアント ID、自己署名証明書のホストごとの信頼設定（検証を無効にするのではなく、SHA-256 フィンガープリントで固定）。システム通信の診断では、証明書チェーン、有効期間、ネゴシエートされた TLS/暗号スイートの識別子、プロトコルを表示します。
- ステータス/時間/ヘッダ/JSONPath/スキーマを視覚的に設定できるアサーション、成功/失敗の結果、編集可能な JavaScript のチェック。
- cURL、JavaScript fetch、Node.js axios、Python requests、Go、Java HttpClient、C# HttpClient、PHP cURL、Ruby Net::HTTP、Swift URLSession、Kotlin OkHttp、HTTPie、PowerShell 向けのコードスニペット。資格情報を伏せるオプションがあります。
- リクエストごとに保存されるレスポンスの例（Postman の `response` の例）、例・現在のレスポンス・スナップショットから作るオフラインのレスポンスモック、待機時間/ステータス/エラーの設定、フォアグラウンドで動作するループバックのモックサーバ。
- Mac と iPad でのリクエストタブ（再起動後に復元）、リクエスト・フォルダ・コレクション用の Markdown ドキュメント、サンドボックス化された HTML レスポンスプレビュー。
- Postman（v1、v2/v2.1 のコレクション、環境、グローバル変数、完全なデータダンプ）、Insomnia（v4 JSON/YAML と v5 YAML）、Bruno（`.bru` フォルダと JSON エクスポート）、Hoppscotch、Thunder Client、HAR、VS Code REST Client/JetBrains の `.http` ファイル、OpenAPI、cURL からの読み込み。複数のファイルやフォルダ全体を一度に選択できます。
- 他のアプリから直接読み込み：Postman、Insomnia、Hoppscotch に各アプリと同じ方法でサインインして同期済みのコレクションを取り込むか、GitHub リポジトリに接続します。すべてのコレクション、環境、グローバル変数が移行されます。セッションとトークンはその読み込みにのみ使用され、保存されることはありません。Monkeytail のアカウントは引き続き不要です。
- Postman v2.1 のコレクション書き出しと Insomnia v4 JSON の書き出し。現行の Insomnia はこの旧形式を読み込めます。
- 情報を失わない Monkeytail ワークスペース JSON の読み込み/書き出し、ファイル App との連携、システムの共有シート。
- 保存したレスポンスのスナップショット。検索、JSON/ステータス/ヘッダの比較、JSONPath による抽出（`$`、キー、インデックス、ワイルドカード）に対応しています。スナップショットはローカルに保持され、最大 50 件・60 MB までです。
- 直近 50 件のリクエスト定義をステータスと所要時間とともに履歴に保存します。復元しても自動で再送信されることはありません。
- ライト/ダークの外観、Dynamic Type、VoiceOver のラベル、ハードウェアキーボードでの送信ショートカット（⌘↵）、縦向き/横向きに応じたレイアウト。

## デバイスごとのレイアウト

サイドバーは Postman と同じように機能します。上部にワークスペースの切り替えがあり、その下にワークスペース内のすべてのコレクションが、入れ子のフォルダとリクエストのツリーとして表示されます。各ワークスペースはそれぞれ独自のコレクション、環境、グローバル変数を持ち、既存のデータは **マイワークスペース** にあります。リクエストやフォルダは **移動先** またはドラッグで移動でき、フォルダは **+** や、各コレクション・フォルダ・リクエストのメニューから追加できます。インターフェイスは英語、スペイン語、フランス語、日本語、韓国語、簡体字中国語に対応しており、デバイスの言語に従います。

色はデフォルトでデザインシステムに従います。**設定 → テーマとフォント** では、6 つのプリセット（Monkeytail、Navy、Ocean、Ember、Grape、Graphite）、システム/ライト/ダークの外観、そしてアクセント、キャンバス、サーフェス、警告、危険、情報、その他のメソッド、エラーの各役割について、ライトとダークの色を個別に設定できます。デバイスにインストールされているフォントから、インターフェイス用とコード用のフォントを別々に選ぶこともできます。テーマはデバイスに保存され、すべてのウインドウにすぐに反映されます。

iPhone のレイアウトでは、コンパクトなエディタの上にメソッドと URL が常に表示されます。**送信/キャンセル** と **リクエスト/レスポンス** は親指の届く画面下部にあり、編集中はキーボードの上に移動します。ヘッダやパラメータの名前と値は、44 ポイントのコントロールとともに 1 行に並びます。iPhone で検索語を入力している間はレスポンスのタブが折りたたまれ、一致した行がキーボードの上に見えるようになります。補足のヘルプは折りたたまれており、リクエスト名はナビゲーションバーで直接編集できます。cURL の共有はアクションメニューにあります。

レイアウトは **利用可能なウインドウサイズ** に従います。

| 利用可能なスペース | レイアウト |
| --- | --- |
| 幅の狭い iPhone / 折りたたんだウインドウ | 下部でリクエスト/レスポンスを切り替え。コレクションは戻る/サイドバーボタンから |
| 詳細領域が 640 × 440 ポイント以上の iPad | リクエストとレスポンスを左右に並べて表示 |
| 高さの低い横向きの iPhone のウインドウ | エディタを使いやすく保つため 1 ペイン表示 |
| 1,100 ポイント以上のウインドウ | コレクションのサイドバーと、リクエストおよびレスポンスのパネル |
| 折りたたみ式デバイスを半開きにし、折り目が画面を横切る状態（テーブルトップ） | ヒンジの上にレスポンス、下に URL、送信、リクエストエディタ。折り目をまたぐ要素はありません |
| アクセシビリティ用の文字サイズ | 読みやすい文字を保つため 1 ペインのエディタ |

選択状態とエディタの状態は、幅の変更、回転、iPad のウインドウサイズ変更、折りたたみ式デバイスのサイズ変更の後も保持されます。iOS 27.1 以降では、テーブルトップのレイアウトは `UIHingeInteraction`（半開き）とシステムの `.division` 予約領域に従うため、分割位置は報告された折り目にぴったり合い、両側に 7 ポイントの余白が確保されます。ヒンジが平らに開いているか閉じている場合、または折り目が水平でない場合は、通常のレイアウトが適用されます。

## Apple Watch コンパニオン

iPhone のアクションメニューでリクエストにスターを付けます。**Apple Watch** を開いてお気に入りをタップしてコピーし、ペアリングされた App がインストールされていれば **同期** をタップします。Watch には最大 10 件のコピーが一覧表示されます。1 件を開いて **送信** または **キャンセル** をタップし、ステータス、時間、ヘッダ、または整形/ロー/Hex のテキストを確認できます。Watch にはリクエストエディタや自動ポーリングはありません。

選択中の環境と、継承されたヘッダ/認証は、コピーした時点で解決されます。**資格情報と本文を含める** は保存されるオプションで、オフにしない限りオンです。コピーはデフォルトでローカルファイルを使用し、オプションでキーチェーンに保存でき、WatchConnectivity の最新のアプリケーションコンテキストを使用します。リクエストを編集したり環境を変更したりした場合は、再度コピーする必要があります。同期を行うと、お気に入りでなくなったコピーは削除されます。Watch は自身で HTTP リクエストを送信するため、サーバは Watch から到達できる必要があります。レスポンスはメモリ上にのみ保持されます。ペアリングされた実機間での転送は、まだハードウェアでの検証が必要です。

Watch では、システムの HTTP/GraphQL、検証済みの HTTPS、手動で設定した Basic/Bearer/API キーのヘッダに対応しています。プロキシ、ブラウザ TLS のプリセット、クライアント ID、Cookie、OAuth/JWT/AWS、スクリプト、モック、WebSocket、SSE はフル機能の App でのみ使用できます。対応していない設定はコピーの前にエラーになります。タイムアウトは最大 30 秒、コピーする本文は最大 32 KB、転送は最大 60 KB、レスポンスは最大 256 KB、表示する本文は最大 16 KB です。

visionOS のウインドウは、iPhone や Mac と同じワークスペースエディタ、レスポンスビューア、API ツール、iCloud コンテナを共有します。visionOS では System TLS を選択してください。ブラウザ TLS のプリセットは使用できません。システム専用および Watch 用の Swift パッケージは、リポジトリに含まれるシンボリックリンクを通じて正規のソースをリンクし、非対応のプラットフォームで iOS/Mac 用の curl バイナリを使わないようにしています。

バージョン 1.4 は、Watch コンパニオン付きの iPhone/iPad、Mac、visionOS 向けに公開されています。バージョン 1.5 は 3 つのプラットフォームすべてで App Review の待機中です。ビルドと検証については[リリース記録](docs/app-store/README.md)をご覧ください。ペアリングされた実機の Watch への転送と、実環境での iCloud 転送は未検証です。

Mac では、デフォルトでリクエストとレスポンスがサイズ変更可能な分割ビューで上下に並びます。**ワークスペースのアクション → ワークスペースのレイアウト** を選ぶと左右に並べられ、分割位置はレイアウトごとに記憶されます。サイドバーは非表示にするまで、サイズ変更中も開いたままです。設定はネイティブの設定ウインドウで開きます。⌘F でリクエストを検索、⇧⌘I で読み込み/書き出し、⇧⌘E で cURL の書き出し、⌘N で新規リクエスト、⌘Return で送信またはキャンセルを行えます。

## 相互運用の範囲

Monkeytail ワークスペース JSON は、すべてのモデルのフィールド、環境、プロキシ設定を保持します。読み込むとコレクションと環境が追加され、新しい ID が生成されます。ネイティブ形式の読み込みでは、保存されたプロキシ設定も適用されます。読み込んだスクリプトは Postman と同様に送信時に実行されます。各スクリプトタブで内容を確認するか、**スクリプトを実行** をオフにするとスキップできます。

Postman への書き出しでは入れ子のフォルダが保持され、**アクティブな環境** がコレクション変数として書き出されます。Postman からの読み込みでは、フォルダの階層と、継承されるヘッダ、認証、変数、スクリプトが保持されます。Raw、URL エンコード、マルチパート、ファイル、GraphQL JSON の本文に対応しています。スクリプトは保持され、実行時には[スクリプト](docs/Scripting.md)に記載された API が使用できます。

Insomnia の v4 JSON/YAML エクスポートと v5 YAML のコレクションは、フォルダツリーとともに読み込まれます。ベース環境はコレクション変数に、サブ環境は環境になり、フォルダの環境、ヘッダ、認証、スクリプトはフォルダのデフォルトになります。`{{ _.variable }}` と `{{ _['variable'] }}` の参照は正規化されます。テンプレートタグ（レスポンスのチェーンなど）は通知が表示され、テキストのまま残ります。gRPC のリクエストはスキップされます。

Bruno のコレクションフォルダ（`bruno.json`、`collection.bru`、`folder.bru`、`environments/`）と JSON エクスポートでは、フォルダ、デフォルト、シークレットの環境変数、スクリプト、アサーション（テストに変換）が保持されます。Hoppscotch のコレクションと環境では、`<<variable>>` の参照が変換され、すべての認証タイプが保持されます。Thunder Client のコレクションでは、宣言的なテストがスクリプトに変換されます。HAR ファイルではリクエストがホストごとにグループ化され、記録されたレスポンスは保存済みの例として保持されます。`.http`/`.rest` ファイルでは、`@variables`、`# @name`、本文、`> {% %}` のレスポンスハンドラが保持されます。これらのクライアント向けに書かれたスクリプトを読み込んだ場合は、互換オブジェクトとともに実行されます。[スクリプト](docs/Scripting.md#other-clients)をご覧ください。

読み込む → **Postman、Insomnia、Hoppscotch、GitHub から読み込む**：

- **Postman：** Monkeytail は Postman のデスクトップ App と同じ方法でサインインします。**Postman にサインイン** を選ぶと、プライベートブラウザセッションで Postman 自身のサインインページ（メールアドレスとパスワード、GitHub、または SSO）が表示され、最後のリダイレクトからセッションを読み取ります。続いて Monkeytail は Postman のゲートウェイを通じてワークスペースを一覧表示し、選択した各ワークスペースのコレクション、環境、グローバル変数を、デスクトップ App が保存しているのと同じ v1 形式で Postman の同期サービスから取得します。US と EU のどちらのアカウントにも対応しています。複数のワークスペースを読み込む場合、環境名の先頭にワークスペース名が付きます。
- **Insomnia：** Monkeytail は Insomnia のデスクトップ App と同じ方法でサインインします。**Insomnia にサインイン** を選ぶと、ワンタイムキー付きで Insomnia の Web サイトが開きます。表示されたコードをペーストしてください。Monkeytail は封印されたサインインボックスを開き、アカウントのエンドツーエンド暗号化キーのロックを解除し、すべての組織の Cloud Sync プロジェクトを一覧表示して、選択した各プロジェクトのデフォルトブランチの最新スナップショットを取得します。ドキュメントはデバイス上で復号されます。Local と Git Sync のプロジェクトは Insomnia のクラウドにないため、GitHub のオプションを使うか、ファイルを書き出してください。
- **Hoppscotch：** メールアドレスを入力してサインインリンクを受け取り、そのリンクを開かずにペーストします。hoppscotch.io では Web アプリのメールリンクによるサインイン、セルフホストのサーバ（バックエンドの URL を入力）ではデスクトップアプリのマジックリンクが使われます。個人のコレクションと環境、グローバル変数、そしてすべてのチームのコレクションと環境が読み込まれます。チームの環境名の先頭にはチーム名が付きます。
- **GitHub：** `owner/repo`、`owner/repo@branch`、またはフォルダの URL（`…/tree/branch/folder`）を入力します。Postman、Insomnia Git Sync、Bruno、Thunder Client、Hoppscotch、`.http`、HAR、OpenAPI のファイルがすべて読み込まれ、Bruno のコレクションはそれぞれの `bruno.json` を基準に解釈されます。公開リポジトリにはトークンは不要です。プライベートリポジトリには読み取り専用の fine-grained トークンを使用してください。読み込めるのは最大 1,000 ファイル、40 MB までです。

Bruno と Thunder Client は、コレクションをファイルまたは Git に保存します。資格情報とセッションは、選択したサービスにのみ、Cookie やキャッシュを使わない一時的なセッションで送信され、読み込み後に破棄されます。

サードパーティの形式では、リクエストのタイムアウトやグローバルなプロキシ選択など、Monkeytail の設定の一部が保持されません。対応していない認証は読み込み時に通知が表示され、対応していない cURL フラグは明示的なエラーになります。読み込んだファイルパスはメタデータにすぎないため、送信前にファイル App または写真 App で各ファイルを選択してください。ネイティブのワークスペースの書き出しにはファイルのバイト列が含まれますが、Postman/Insomnia/cURL の書き出しではファイル名を参照するだけです。サードパーティ向けの書き出しと一緒に実際の添付ファイルを渡すには、本文 → ファイルを書き出す を使用してください。gRPC、アカウントとチームワークスペース、クラウドのモニタ/モック、他のクライアントの完全なスクリプトランタイムは、このバージョンの対象外です。Monkeytail がログインを求めることはありません。OpenAPI の読み込みと JSON Schema の検証には、明示的に定められた対応範囲があります。[API ツール](docs/APITools.md)をご覧ください。

ブラウザプロファイルは、ネイティブの JSON と `curl-impersonate --impersonate` コマンドを通じて往復変換されます。Postman と Insomnia への書き出しには、Monkeytail に再度読み込むための `_monkeytail` メタデータが含まれます。これらのアプリ自体はブラウザプロファイルを適用しません。

## データとネットワーク

ワークスペースと履歴は App の Application Support ディレクトリに保存され、プラットフォームのファイル保護と Mac App のサンドボックスを使用します。ワークスペースの資格情報と履歴は、デフォルトでローカルファイルを使用します。**キーチェーンを使用** はオプションで、ワークスペースの資格情報、Cookie、クライアント ID、Watch 用のコピーに適用されます。このオプションがオフの場合、起動時にキーチェーンを参照することはありません。以前のキーチェーンの値はそのまま残り、オプションを有効にすると復元できます。書き出しには保存済みの値が含まれます。分析機能や Kitta が運用するバックエンドはありません。iCloud Drive 同期はデフォルトでオンです。バージョン 1.6.3 では既存のインストールでも一度だけオンになります（ローカルのみで使う場合は、設定で **iCloud 同期** をオフにしてください）。同期はコレクション、環境、スクリプト、資格情報をデバイス間で共有し、エンティティごとに最新の編集でマージし、削除の tombstone を保持します。異なるリクエストへの編集は、同時に変更しても失われません。同じエンティティについては最新の編集が優先されます。リモートの変更を適用する前に、保護されたローカルの復元用コピーが保存されます。App はオフラインでも使用でき、同期の確認はアクティブな間とフォアグラウンドに戻ったときに行われます。**資格情報を含める** は、認証や資格情報のフィールドを iCloud 同期の対象にするかどうかを制御します。オフにしない限りオンなので、デフォルトではすべてが同期されます。Cookie、クライアント ID、添付ファイル、スナップショット、リクエスト履歴はローカルに残ります。`Authorization` や `X-API-Key` などのフィールドは自動的に機密扱いにはならず、表示されたままです。値を伏せるには **機密としてマーク** を使用します。**資格情報を含める** がオフ、**キーチェーンを使用** がオン、またはコードの非表示がオンの場合、資格情報らしい名前のフィールドは、通常の項目としてマークしない限り引き続き保護されます。読み込み/同期したスクリプトは、デバイスごとに有効化が必要です。デバイスの iCloud セッションを切り替えるには、同期をいったんオフにしてからオンに戻す必要があります。レスポンスの本文は、スナップショットとして明示的に保存するか書き出すまでメモリ上に保持されます。オーディオ/ビデオのプレビューは保護された一時ファイルを使用し、キャッシュされたレスポンスが解放されると削除されます。中断されたセッションで残ったファイルは、1 日経過後の起動時に削除されます。明示的に保存すると、元のバイト列が書き出されます。Cookie はリクエストごとのオプトインで、環境ごとに別々のデバイスローカルな jar を使用します。セッションで Safari の Cookie が使われることはありません。OAuth はプロバイダを一時的なブラウザセッションで開き、Monkeytail のアカウントを作成することはありません。クライアント ID はデバイスローカルに、ファイルまたはオプションのキーチェーンに保持されます。モックサーバは 127.0.0.1 にのみバインドし、App がバックグラウンドに移ると停止します。TLS の信頼性検証は有効なままです。必要に応じて、iOS の設定でデバッグ用 CA をインストールして信頼してください。この App は汎用の API/デバッグクライアントであるため、ATS で HTTP を許可しています。

レスポンスの上限は 20 MB、テキスト/ツリーとバイト列のプレビューの上限は 1 MB です。画像は最大 2,048 ピクセルのプレビューにデコードされ、保存時には元の画像が保持されます。オーディオ/ビデオの再生はダウンロードしたファイルのみを使用し、外部メディアの参照は無効になっています。JSON の整形、ツリーの準備、行の分割はメインスレッド以外で実行されます。テキストとツリーの行は遅延描画され、検索中は行の配列が再利用されます。シンタックスハイライトはコンパイル済みの単一の正規表現を使用し、長い行には長さの上限を設けています。レスポンスキャッシュは 40 MB の範囲内で最大 8 件のレスポンスを保持します。読み込みの上限は 40 MB、アップロードは 20 MB、iCloud のメタデータは 20 MB です。JSONPath と JSON の差分は、最大 2 MB の本文に対して、ノード数/変更数の上限付きで動作します。JavaScript のコンテキストには 3 秒の制限時間があり、一時的な WebKit データストアを使用し、ネットワークや DOM への直接のナビゲーションはブロックされます。ネイティブとの唯一のブリッジは `pm.sendRequest` で、選択したプロキシを経由して 1 スクリプトあたり 10 件の HTTP(S) リクエストまでに制限されています。ファイルや App へのブリッジはありません。タイムアウトしたコンテキストは破棄されます。スクリプトは利便性のための API であり、汎用の Node.js ランタイムではありません。

## 検証

モデル、パーサ、コレクション、エンコーディング、JSON、プロキシ設定、マルチパート、同期のマージ/tombstone/シークレット、JSONPath、レスポンス比較の純粋なテスト：

```sh
swift test
```

シミュレータでの統合テストと UI テストは、ローカルの HTTP、TLS/HTTP2、CONNECT、SOCKS5 のフィクスチャを使用し、公開 API には依存しません。

```sh
./Scripts/test.sh 'platform=iOS Simulator,name=iPhone Duo'
# Or pass another installed simulator destination, e.g.:
./Scripts/test.sh 'platform=iOS Simulator,name=iPhone 18 Pro,OS=27.0'
```

このテストスイートでは、通信、実際に送信される TLS ClientHello と HTTP/2 SETTINGS、証明書の拒否、ブラウザヘッダの上書き、リダイレクト、オリジンをまたぐ際の資格情報の削除、キャンセル、各種上限、両方のプロキシプロトコル、スクリプトによる変更/アサーション/エラー/タイムアウト/ネットワークのブロック、キーチェーンへの保存、スナップショットの削除、両方の通信方式でのマルチパート/バイナリのアップロード、ホップごとの診断、そして縦向きと横向きでの「送信 → 確認 → 読み込み → 編集 → cURL 書き出し」の UI フローを検証します。UI テストは分離された一時的なワークスペースを使用し、通常のユーザのコレクションは変更しません。

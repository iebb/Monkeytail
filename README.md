Monkeytail is an open-source API client for iPhone, iPad, Mac and Apple Vision Pro, built with SwiftUI. It imports cURL, Postman, Insomnia and OpenAPI, and supports scripts and tests. No account needed.

## Build

Open `Monkeytail.xcodeproj` in Xcode and run the **Monkeytail**, **MonkeytailMac** or **MonkeytailVision** scheme. After editing `project.yml`, run `xcodegen generate`.

## Test

```sh
swift test
```

# Media fixture

`sample.mp4` is a synthetic two-second teal frame with a quiet 440 Hz tone. It contains no third-party media. Recreate it with:

```sh
ffmpeg -f lavfi -i 'color=c=0x167b67:s=320x180:d=2' \
  -f lavfi -i 'sine=frequency=440:duration=2' \
  -c:v libx264 -pix_fmt yuv420p -c:a aac -movflags +faststart sample.mp4
```

PNG, WAV, arbitrary bytes, and invalid media are generated by `fixture_server.py`.
